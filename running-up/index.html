Running Up

生活节律网页 MVP

面向作息改善与自我管理场景，帮助用户把“想早睡、想运动、想规律饮食”拆成每日可执行计划，并通过记录与反馈形成习惯闭环。

Product Case

项目拆解

角色：产品策划 / UI 设计 / Vibe Coding 开发。核心是用轻量网页 MVP 验证学生作息管理的完整流程。

核心功能

  • 目标设定：早睡、运动、饮食与学习任务可配置。
  • 睡前计划：生成今晚行动清单，降低执行门槛。
  • 睡眠记录：记录入睡/起床时间，追踪节律变化。
  • 个性化反馈：根据完成度给出第二天建议。
1. 设定目标选择作息、运动、饮食、学习目标。
2. 生成计划拆分今晚/明早可执行动作。
3. 记录完成用本地存储保存每日状态。
4. 反馈迭代根据完成度输出下一步建议。
Demo 界面概念
今日目标：23:30 前入睡 · 晨跑 20min · 饮水 1.5L
睡前清单：整理书桌 / 关闭短视频 / 明日计划
反馈：完成度 86%，建议明天提前 15 分钟进入睡前流程。
