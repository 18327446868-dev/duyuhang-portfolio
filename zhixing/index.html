项目拆解

角色：产品策划 / AI 交互设计 / UI 设计 / Vibe Coding 开发。核心是把复杂通知转化为清晰行动。

核心功能

  • 文件导入：支持 PDF、DOCX、TXT 等通知材料。
  • 信息提取：识别时间、地点、对象、材料、截止日期。
  • 待办生成：把通知转化为可执行任务清单。
  • 通知问答：围绕原文进行检索与解释，减少漏看误读。
1. 导入通知上传文件或粘贴通知原文。
2. AI 提取抽取关键时间、事项和报名要求。
3. 生成待办转化为可勾选任务和提醒。
4. 问答追溯提问并查看对应原文依据。
